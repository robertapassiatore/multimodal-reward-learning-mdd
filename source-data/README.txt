# Figure reproduction

This folder contains the source data and plotting scripts used to reproduce the manuscript figures.

## Files

- `Source Data.xlsx` — source-data workbook containing the numerical values used by the plotting scripts.
- `plot_figures.R` — R script used to generate Figure 2 and the R-based Supplementary Figures.
- `plot_figure.py` — Python script used to generate the remaining main and Supplementary Figures.

Both scripts read the required data directly from the corresponding sheets in `Source Data.xlsx` and save the generated figures in a `figures` subfolder.

## Figures generated by each script

### `plot_figures.R`

- Figure 2
- Supplementary Figures 5, 6, 7, 8, 9, 10, 13, 16, 17, and 18

### `plot_figure.py`

- Figures 3, 4, and 5
- Supplementary Figures 11 and 12

## Usage

Keep `Source Data.xlsx` and both scripts in the same directory.

### R figures

Required R packages:

`readxl`, `ggplot2`, `dplyr`, `tidyr`, `patchwork`, `ggdendro`, `ggnewscale`, `lme4`

Run from R/RStudio or from the command line:

    Rscript plot_figures.R

### Python figures

Required Python packages:

`pandas`, `numpy`, `matplotlib`, `scipy`, `openpyxl`

Run:

    python plot_figure.py

The scripts automatically create the `figures` directory if it does not already exist. Figures are exported in publication-quality formats (PDF, PNG, and/or SVG, as specified in the scripts).

## Notes

The scripts assume that the workbook is named exactly `Source Data.xlsx`. Sheet names and variable names should not be changed, because they are referenced directly by the plotting code.
